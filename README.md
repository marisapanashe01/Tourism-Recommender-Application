# 🌍 Tourism Recommender App

A mobile tourism application developed using **C#, .NET MAUI, and XAML**, designed to provide an interactive way to explore tourism destinations.

This project was developed as part of my software engineering journey, applying mobile application development concepts to a tourism-focused use case.

## 📱 Application Screenshots

The application was built and tested on a physical Android device. Screenshots captured during testing are available in the folder below.

📸 **[View Application Screenshots](https://github.com/marisapanashe01/Tourism-Recommender-Application/tree/main/ToursmApp3/Tour3Images/New%20folder)**

## ✨ Key Features

- 🗺️ **Destination Exploration** — browse tourism destinations through the application interface.
- 🖼️ **Visual Presentation** — display destination images alongside available information.
- 📱 **Interactive User Interface** — navigate the application through its XAML-based layouts.
- 💾 **Local Sample Data** — demonstrate the application's functionality using locally available mock data.

## 🧩 How It Works

The application provides a mobile interface for exploring tourism destinations. Its interface is built with XAML, while C# handles the application's logic. Locally available sample data is used to demonstrate the application's functionality.
